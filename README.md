# SB선보 2026 복지가이드 AI 음성 챗봇

SB선보 임직원을 위한 음성 대화형(STT/TTS) 복지 가이드 챗봇 및 관리자 로그 분석 시스템입니다.
PC 로컬 테스트와 Netlify 무료 호스팅 및 Supabase DB 연동을 완벽하게 지원합니다.

## 🚀 주요 기능
1. **음성 대화 인터페이스**: Web Speech API 기반 음성 인식(STT) 및 음성 답변(TTS) 탑재
2. **2026 복지가이드 RAG 탑재**:
   - 의료비, 종합검진, 난임시술, 임신기 단축근무
   - 학자금 및 자녀 대학 등록금, 초·중·고·대학 입학축하금
   - 경조휴가 및 경조금, 사우회 경조비 및 운구 지원
   - 장기근속 포상, 기념일 조기퇴근, 워라밸(가정의 날/반반차)
   - 송도 힐스테이트 휴양사택 및 콘도·리조트
   - 선택적 복지수당(연 100만원), 주택마련 축하금 및 사내대출
3. **사용자 / 관리자 권한 분리**:
   - 일반 임직원: 챗봇 질문 및 음성 청취
   - 인사/총무 관리자: 질문 로그 실시간 모니터링, 관심 카테고리별 질문 비중 분석 대시보드
4. **PC 로컬 테스트 지원**: 더블클릭만으로 즉시 작동 (Supabase 미연결 시에도 LocalStorage 모드로 100% 정상 작동)
5. **Netlify 배포 최적화**: 정적 사이트로 index.html을 드래그 앤 드롭하여 10초 만에 배포 가능

## 📁 파일 구성
- `index.html`: 메인 웹페이지 (챗봇 + 관리자 대시보드 + 로그인 모달)
- `js/config.js`: Supabase URL 및 Anon Key 설정 자리표시자
- `js/welfare_data.js`: 2026 선보 복지 가이드북 원문 데이터베이스
- `js/app.js`: STT/TTS 음성 엔진, 검색(RAG), 권한 및 분석 로직
- `css/style.css`: 모던 반응형 UI 스타일시트

## 🛠️ Supabase 테이블 생성 SQL (1분 설정)
Supabase 대시보드 -> SQL Editor에 복사하여 붙여넣기 후 Run:

```sql
create table if not exists chat_logs (
  id bigint generated by default as identity primary key,
  user_email text,
  user_name text,
  query text,
  answer text,
  category text,
  created_at timestamp with time zone default timezone('utc'::text, now())
);

-- RLS 활성화 및 익명 읽기/쓰기 허용 (데모용)
alter table chat_logs enable row level security;
create policy "Allow public insert" on chat_logs for insert with check (true);
create policy "Allow public read" on chat_logs for select using (true);
```
